Hold-tap tuning

KeyFlavortapping-term-msquick-tap-msrequire-prior-idle-ms
Space / NAVbalanced200175150
Space / NUMbalanced200175—
Tab / Ctrl, Enter / Ctrlbalanced200175150
  • quick-tap-ms: tap then hold repeats the tap key, e.g. hold Space for repeated spaces.
  • require-prior-idle-ms: pressed mid-word, the key is a plain tap, which prevents misfires.
  • Space / NUM has no require-prior-idle-ms; otherwise typing port 8080 quickly would give letters instead of digits.
  • Super and Alt are plain keys with no hold-tap, so typing can never fire Super+q or Super+n.

Design

  1. Super is a plain key under the left thumb, on the stock Alt position.
  2. One layer per thumb. Left Space holds NAV, right Space holds NUM; both type a space when tapped.
  3. Ctrl on the home row: hold Tab or hold Enter.
  4. No arrow cluster. Arrows live on hjkl in NAV; the freed keys hold ' / -.

Optional extras

  • Combo J+K = Esc, popular with Helix users.
  • xkb variant altgr-intl: us intl makes ' " ` ~ ^ dead keys; altgr-intl keeps accents behind AltGr.

Dropped from stock

Mouse keys (trackpad available), Win+V, Print Screen (mango uses Super+Shift+S), Insert, Pause, Scroll Lock.
